# DEAD SIGNAL

霧の封鎖区域を舞台にした、1人用3Dゾンビ・アーケードシューティング。全5ウェーブを生き延び、最終ウェーブの変異体を倒すとクリアです。

各エリアをクリアすると、向きを変えながら次の戦闘地点へ移動します。移動は安全確認1.2秒＋退出・進入のカメラ演出5秒。場面の接続には短い暗転を挟みます。移動中は射撃・手榴弾・リロード・武器切替を停止し、到着時に体力20回復と弾倉補充を行います。移動中の一時停止にも対応しています。

## 全5エリアと分岐先

- **封鎖検問所**：正面から街路を防衛。車両とバリケードの脇から敵が進入。
- **裏路地・死角**：低い位置から斜めに狙う狭い路地。ゴミ収集箱・木箱の陰から敵が回り込みます。
- **大通り・包囲線（分岐先）**：裏路地の代わりに選べる、商店の並ぶ開けた道路。感染者15体と射手12体が、車両・資材の陰や高所から出現します。
- **病院・救急ロビー**：天井のある室内。診察室の扉、仕切り、受付カウンターを挟んだ戦闘。
- **倉庫・搬入デッキ**：一段高いデッキから見下ろします。敵はコンテナの間を抜け、階段を上って接近。
- **屋上・最終退避地点**：開けた空とヘリポート。空調設備の両脇と中央の隔離扉から進入し、最後にボスが出現。

戦闘開始9秒後から約5秒かけて、同じエリア内でもカメラの位置と向きが変化します。壁や荷物に当たった弾は遮られ、ショットガンの周辺ダメージにも射線判定があります。敵は配置物を避けた経路で接近します。手榴弾は物陰にいる敵も含めて全敵にダメージを与えます。

検問所クリア後に一度だけ進路を選択します。「裏路地を抜ける」は猟犬・蜘蛛・這虫が中心の近距離戦、「大通りを進む」は感染者と射手を相手にする中〜遠距離戦。地形・出現編成・カメラの退出方向が変わり、どちらも次の病院で合流します。その後は倉庫、屋上へ自動で移動し、1プレイは全5エリアです。

ルート選択に時間制限はなく、選択中は射撃・被弾・移動が停止します。クリック、またはTabとEnterで選択でき、P・Escでの一時停止にも対応。ハート2個相当の回復と弾倉補充は、選択後の移動が完了した時に行います。再出撃では選択をリセットします。

出現経路は各エリア8か所（1プレイ40か所、分岐先を含め全48か所）。敵ごとに利用できる入口から、使用回数の少ない場所を優先してランダムに選びます。同じ入口の連続使用を避け、出現後0.65秒は移動・攻撃を待ちます。この間も敵を撃てます。

| エリア | 追加した出現場所 |
| --- | --- |
| 検問所 | 左の放置車両、右の資材置場、道路の陥没口、右手前の工事資材、射手のバルコニー |
| 裏路地 | 左の通風口、右のごみ収集箱、奥の排水口、左奥の積み荷、蜘蛛が降りる右壁の窓 |
| 病院 | 左右の医療物資・機材、受付裏の床下、診察室の通風口、天井の蜘蛛の巣 |
| 倉庫 | 左右の搬入荷物、左右コンテナ前の積み荷、コンテナ上の射手 |
| 屋上 | 左の空調設備の陰、空調設備上の射手、左右上空・隔離棟上空のコウモリ |

追加の独立した扉・入口看板は置かず、車両・ごみ収集箱・積み荷・医療機材・空調設備の陰で敵を隠します。敵は遮蔽物の脇を回り込んでから接近し、遮蔽物は弾も遮ります。高所の射手は足場に留まって狙撃し、通風口・天井・上空は敵の種類に応じた専用経路を使います。HUD左下には直近の敵と出現場所を表示します。

開始画面の「出撃地点」から各ステージを直接選べます。エリア2以降から始める練習ではハイスコアを保存しません。通しプレイの記録はエリア1から開始してください。

## 起動

このフォルダで `npm run dev` を実行し、http://127.0.0.1:4180/ を開いてください。Node.jsとWebGL 2対応ブラウザが必要です。依存ライブラリは同梱済みです。

## 操作

プレイヤーの体力は最大10個のピクセル調ハートで表示します。1個が体力10相当、端数は半分のハート単位で切り上げ表示。体力30以下では点滅し、エリア移動後の体力20回復でハート2個分が戻ります。

## 病院の救出イベント

病院で戦闘開始4秒後に、青緑の服を着た生存者が助けを求めます。通常の敵33体に加え、オレンジの▼を付けた感染者3体が2秒間隔で出現し、生存者へ向かいます。画面上部に生存者のハート3個と救出対象の残り敵数を表示します。

目印の感染者3体を倒すと救出成功。プレイヤーのハート2個分を回復（最大10個）、500点を加算し、生存者が8秒間、約0.7秒ごとに援護射撃します。援護は生存者から射線が通る敵へ1ダメージを与え、撃破はスコア・撃破数に加算します。援護はプレイヤーの弾薬や射撃命中率に影響しません。

生存者が3回攻撃されると救出失敗となり、負傷して撤退します。報酬はなく、残る救出用の感染者はプレイヤーへ向かいます。通常の戦闘は継続でき、残敵を排除すれば次のエリアへ進めます。生存者はプレイヤーの誤射・手榴弾では負傷しません。

一時停止中は救出の出現時刻・敵の攻撃・援護時間も停止。再出撃でリセットし、エリア移動やゲーム終了時には生存者と援護を片付けます。「出撃地点 → 03 病院・救急ロビー」で直接試せます。

## 武器と入力

初期武器は60発装填のマシンガン。毎秒約10発で連射し、押し続けている間は弾切れ時に自動リロード（1.1秒）して再開します。予備弾薬は無制限。ボタンを離す・一時停止・武器切替・エリア移動で連射を止めます。ショットガンは1回押すごとに発射します。

- マウス移動：照準。左ボタン長押し：連射。タッチ画面は押したまま照準を動かして連射。
- R / 右クリック / RELOAD：リロード。予備弾薬は無制限。
- 1・2 / 武器名：マシンガンとショットガンを切替。
- G / 手榴弾ボタン：全敵にダメージ。1プレイ3個。
- P・Esc / 一時停止：ポーズ。別タブや別ウィンドウへ移ると自動停止。
- 矢印キー：照準移動。Space長押し：連射。
- SOUND：効果音の切替。⛶：全画面。

## ブロック調の敵キャラクター

Minecraftの敵の役割を参考に、コードで作成した6種類のモデルと行動を追加しています。開始画面の「敵図鑑」からアニメーション付きの3Dモデルと特徴を確認できます。

図鑑には通常の感染者と変異ボスも掲載しており、合計8種類を閲覧できます。

敵モデルは面取りしたブロックを使って作り直しています。感染者の裂けた服・指・歯、射手の立体的な肋骨・関節・矢筒、爆裂体の苔と外殻、猟犬の毛並み・牙・肉厚な足、コウモリの翼膜と翼骨、這虫の装甲節と触角、蜘蛛の屈曲した脚と六つの目を造形。ボスには胸筋・腹筋・肩の突起・巨大な指・壊れた拘束具を追加しました。顎・肘・膝も独立して動きます。細部は関節ごとにまとめて描画し、モデルの形状データを同種の敵で共有します。

ゾンビのうなり、接近時の威嚇、被弾、撃破、ボスの咆哮を合成音声で追加。敵の種類によって声の高さが変わり、距離による音量と左右の位置も反映します。同時発声は最大3体。SOUND OFF・一時停止・戦闘終了・エリア切替で発声中の音を止めます。

検問所ではドラム缶・車両・積み荷を避ける経路に修正し、物陰での出現位置に余裕を追加しました。頭や胴体の中心だけでなく、動く腕・脚・弓を含めて遮蔽物と重ならないことを検証します。

| 敵 | 行動 | 対処 |
| --- | --- | --- |
| 骨の射手 | 射線の通る場所で止まり、弓を構えてから矢を放つ | 発射前に倒す。飛んでくる矢を撃つと迎撃・25点 |
| 苔の爆裂体 | 接近すると点滅し、約1.7秒後に自爆 | 点滅中に撃破すれば自爆を阻止。自爆による消滅には得点なし |
| 灰牙の猟犬 | 小さな四足の体で高速接近 | 低い位置を狙って早めに止める |
| 夜羽コウモリ | 羽ばたきながら飛び、最後に降下 | 頭上も警戒。体力は1 |
| 銀殻の這虫 | 節のある小さな体で地面を這う | 足元を狙う。ショットガンも有効 |
| 八脚の潜伏者 | 八本脚で低く走り、物陰から接近 | 横に広い脚と赤い目を探す |

通常の感染者と最終ボスも登場します。エリアごとに出現する敵の組み合わせが変わります。矢は壁や荷物に遮られ、一時停止中は矢・射撃予告・自爆カウントも停止します。次のエリアへ移ると残った矢は消えます。

各エリアでは主力の敵が過半数を占めます。開始画面には選択したエリアの敵の内訳と攻略ヒント、戦闘中には出現傾向を表示します。

敵の総数は従来の3倍（21・27・33・39・45体＋最終ボス）、通常敵の移動速度は20％増加。出現間隔は約0.3〜0.6秒で、同時に活動する通常敵は最大16体です。撃破すると次の敵が補充されます。撃破時の大きなブロック破片、吹き飛び、曳光弾、薬莢、連続撃破の表示と効果音を追加しています。破片は最大320個をまとめて描画します。

| エリア | 敵の構成 |
| --- | --- |
| 封鎖検問所 | 感染者12・射手9。基本の射撃と矢の迎撃 |
| 裏路地・死角 | 猟犬15・蜘蛛9・這虫3。高速の小型敵が中心 |
| 病院・救急ロビー | 這虫15・蜘蛛12・射手6。床付近への警戒が中心 |
| 倉庫・搬入デッキ | 爆裂体20・射手13・感染者6。自爆型の間に別の敵が出現 |
| 屋上・最終退避地点 | コウモリ27・射手12・猟犬3・蜘蛛3＋最終ボス。空中への対応が中心 |

## ボス：変異巨人・番人

大きな肩と拳を持つブロック調の変異ゾンビ。耐久110。屋上の開けたヘリポートで次の行動を使います。

| 行動 | 予告・対処 |
| --- | --- |
| 遠吠え | 腕を広げて咆哮。音と振動が発生し、この間は反撃のチャンス |
| 岩投げ | 岩を持ち上げてから投げる。飛来する岩はマシンガン3発・ショットガン1発で破壊でき、100点。命中すると22ダメージ |
| 左右への高速回避 | 短い構えの後、左右へ素早く移動。移動先を狙う |
| ジャンプ攻撃 | しゃがんでから高く跳び、着地で16ダメージ。構えから着地までに6ダメージを与えると攻撃を阻止 |
| 飛びかかり | 構えてから低く前方へ跳び、24ダメージ。構えから着地までに6ダメージを与えると攻撃を阻止 |

ジャンプと飛びかかりは、頭へのマシンガン2発・ショットガン1発でも阻止できます。中断時と攻撃後には隙が生まれます。手榴弾でも攻撃を中断でき、飛来中の岩も破壊します。一時停止中はボスの行動と岩も止まり、ボス撃破時には残った飛来物を消去します。

「出撃地点 → BOSS 変異巨人 / 一騎打ち練習」でボス戦だけを開始できます。体力・弾倉・手榴弾は通常の開始状態で、練習のスコアはハイスコアに保存しません。

通常の敵はマシンガンで胴体3発、頭1発。走る敵は胴体2発。ショットガンは周囲にもダメージが入ります。赤茶色のドラム缶は撃つと爆発します。連続撃破で最大5倍のスコア倍率。ウェーブ間に体力20回復と弾倉補充があります。ハイスコアはブラウザ内に保存します。

## 検証・配布

`npm test` でゲームルールを検証。`npm run build` で `dist/` に静的ファイルを生成します。`dist/` の中身を静的ホスティングへ配置できます。HTMLのダブルクリックではなくHTTPサーバーで開いてください。ゲーム本体の外部通信やCDN依存はありません。3Dモデル、ステージ、効果音はコードで作成しています。Three.jsのライセンスは `vendor/THREE-LICENSE.txt` に同梱。
